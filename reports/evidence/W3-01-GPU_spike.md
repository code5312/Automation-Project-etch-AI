## 판정 기준

1. **환경 성립**: 드라이버 570+/CUDA 12.0+/GCC 12+ 확인, ViennaLS 5.8.5 + ViennaPS 4.5.0
   (GPU 플래그 ON) 빌드 성공 — 하나라도 실패하면 **중단**(시간상자 내에서 대안 없음)
2. **물리 결과 일치**: r0004 재실행 결과의 `params_hash`가 CPU 기준과 동일(파라미터 재현 확인)
   하고, `actual_k` 일치 + `final_depth_um` 차이가 **[제안: 1µm 이내]**(설계서 §14 "비결정
   요소 목록화·허용오차" 요구에 따른 임의 제안값 — 사용자 확인 필요)
3. **속도 이득**: `wall_sec` 기준 CPU 대비 배율이 **[제안: 3배 이상]**이어야 N=400 생성 계획을
   바꿀 실익이 있음(현재 CPU 추정 ~3일이 이미 예산 안에 들어오므로, 이득이 작으면 전환 불필요)
