# W7-03 · 대시보드 서빙 복구

- [확인] 격리한 로컬 Compose에서 `docker compose up -d --no-build`로 서빙을 시작했다. 체크포인트 해시 불일치, 해시는 일치하지만 읽을 수 없는 체크포인트, 잘못된 모델 카드 JSON, 레시피 범위가 빠진 카드에서 인증된 `/model`과 `/api/predict`가 각각 503을 반환했다.
- [확인] 같은 프로세스에서 파일을 복구하자 인증된 `/model`이 검증용 RunPod 후보 ID를 반환했다. Chrome에서 `r0007`의 2분·5분 예측, 동일 축척 겹치기, 같은 모델 ID가 포함된 PNG를 확인했다. 비교·이력 화면은 저장소 증빙에서 재구성한 로컬 검증 자료로 확인했다.
- [확인] Git을 설치한 임시 서빙 컨테이너에서 `python -m pytest tests/unit -q -rs`는 244건 통과, FNO 원본 체크포인트가 필요한 3건은 건너뛰었다. 신규 회귀 테스트는 체크포인트·모델 카드 누락, 카드 JSON·레시피 범위 오류, 해시 불일치, 체크포인트 로드 실패와 복구를 포함한다.
- [미확인] 팀 배포 환경의 현재 champion 및 원본 비교·이력 자료, CI 결과, W7-03의 시뮬레이션 및 게이트 시나리오.
