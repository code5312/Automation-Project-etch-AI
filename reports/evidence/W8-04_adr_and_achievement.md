# W8-04: ADR 정리, 정의서 대비 달성/미달 표

## 1. ADR 정리

5건 전부 "승인"됐고 폐기된 ADR은 없다. 서로 겹치는 영역(게이트 판정)이 있어 **어느
ADR이 현재 유효한지** 표로 정리한다 — 과거 ADR의 본문은 역사적 기록이라 고치지 않고,
`0001-interface-freeze.md` §3·§5에 "현재는 다름" 상태 갱신 주석만 추가했다(이번에).

| ADR | 날짜 | 무엇을 정했나 | 현재 상태 |
|---|---|---|---|
| 0001 인터페이스 동결 | 2026-10-28 | `meta.json`/`dataset_hash`/게이트 종료코드/레지스트리/서빙 API 스키마 2주차 동결 | 스키마 틀 자체는 유효. 종료코드 **판정 기준**은 0004·0005로 대체(주석 추가). `/predict` 응답에 `clamped` 필드가 순수 추가됨(주석 추가) |
| 0002 자동 반복 재학습 | 2026-11-02 | C8을 "1회 완주"에서 "게이트 통과까지 최대 4회 자동 재시도"로 변경 | **그대로 유효** — W6-05/06/07, W7-07이 전부 이 구조로 동작 확인 |
| 0003 부호 SDF 규약 | 2026-11-03 | ADR-0001이 비워 둔 SDF 좌표계·부호 규칙 확정 | **그대로 유효** |
| 0004 Chamfer 통일 + 게이트 재구성 | 2026-11-11 | 골든셋 공식 채점 노트북 기준으로 Chamfer 정의 통일, 게이트 규칙 1차 재구성 | **부분 대체** — 물리 위반(선 꼬임) 판정은 그대로 유효(0005도 "변경 없음"이라 명시), 성능 판정 쪽은 0005가 다시 바꿈 |
| 0005 레시피별 통과율 + 통계 검정 | 2026-11-13 | 게이트를 "골든 평균" 대신 "레시피별 깊이·CD·롤아웃 3조건 통과율 90%"로, 승격 기준에 윌콕슨 검정 추가 | **현재 유효(결정1·2·2-1·3·5·6)** — 관문 B(정기 재학습 개선 검정)는 "정기 재학습 코드패스 없음"이라 범위 제외로 명시 |

**결론**: 게이트 판정의 현재 유효한 기준은 **ADR-0005(성능) + ADR-0004(물리 위반, 변경
없는 부분)**이고, ADR-0001 §3은 "최초 설계였다"는 역사적 기록으로만 남긴다. 이 관계가
문서 3곳에 분산돼 있어 혼란 가능성이 있었으나(ADR-0001 단독으로 읽으면 옛 기준처럼
보임), 이번에 ADR-0001에 상태 주석을 추가해 명확히 했다.

## 2. 정의서 대비 달성/미달 표

`docs/project-definition.md`의 §3(합격기준)·§4(목표)·§5(범위)·§6(표현규칙)·§7(데이터)·
§9(평가지표)를 항목별로 대조한다. 상태는 4단계: **달성**(실행 증거로 확인) /
**부분달성**(됐지만 조건·한계 있음) / **미달**(시도했으나 완료 못함, 구현만 있고 미실측
등) / **범위 외**(처음부터 "안 한다"고 정의된 항목, 미달 아님).

### §5 범위

**5.1 필수** — 전부 달성: 시나리오(2D 트렌치 1종), 정답데이터(ViennaPS), 모델 A/B+베이스라인
2종(zero-displacement, MLP — `W3-07_baselines.md`), 자동화 7종(해시버전/학습/평가/게이트/
레지스트리/서빙/재학습트리거) 전부 구현·실행 확인, 시뮬레이션 스윕(kind 1회 성공,
`W1-S4`), CI 1주차부터 상시(`pr-check.yml` 1주차 커밋부터), 대시보드 3화면(`W7-01`).

**5.2 선택(증거①② 확보 후 착수)** — **범위 외(의도된 미착수)**: 레시피 추천, active
learning, 비용 지표, 가상 데이터 실시간 수집 시연. 증거①②는 5~6주차에 확보됐지만, 남은
기간을 필수 범위 마감(대시보드·문서·안정화)에 썼다 — CLAUDE.md 8항·정의서 §5.2 조건을
어긴 게 아니라, 조건이 충족된 뒤에도 우선순위상 손대지 않기로 한 것[제안, 일정상 선택].

**5.3 제외** — 범위 외, 그대로 유지: 실제 장비 제어, 3D, KMC/MD, 실제 fab 데이터. 제외
기술(PhysicsNeMo Curator, ONNX/Triton, Slurm, MLflow, DVC, Transolver) 전부 미사용 확인.
