## 1. 밀린 항목 전수 점검

체크리스트 전체에서 "보류"/"후속 단계"/"나중에"로 표시된 줄을 모두 다시 확인했다.

| 위치 | 내용 | 현재 상태 |
|---|---|---|
| W3-01(줄 77) | `rays`·`grid_delta` 정확도-속도 트레이드오프 미검증, 재검토 트리거(표면 노이즈/SDF 이상/롤아웃 오차 과도) 정의됨 | **트리거 미발동**[확인] — W3~W7 전체에서 표면 노이즈·SDF 이상 리포트 없음(`reports/evidence/W3-*`), 롤아웃 최종 오차(Chamfer 0.373µm, 깊이오차 1.126µm, val-40)도 베이스라인(8.552/2.397) 대비 뚜렷이 개선돼 "과도"로 판단할 근거 없음. **여전히 미확인 상태로 남지만 긴급하지 않음** — W8-07 향후 과제 목록에 11번째로 추가(아래) |
| W3-12(줄 133) | ①외부 배포본 재업로드 "후속 단계" ②OOD +100건 확장 "보류" | ①은 W8-03에서 **재업로드하지 않기로 최종 결정**(사용자 결정, 2026-11-14) — 더 이상 "후속 단계"가 아니라 영구 한계로 확정됨, 이 줄의 표현이 그 결정 이전 상태라 갱신 필요. ②는 정의서 §7.3이 이미 OOD=20을 최종 수치로 확정했고 `data/splits.json` 실측도 20(W7-08에서 확인) — **+100건은 처음부터 "만약"이었을 뿐 합의된 목표가 아니었다**, 프로젝트 종료 시점에 신규 착수하지 않음을 확정 |
| W6-03/04(줄 368,384,387) | 실제 드리프트 시뮬레이션·미세조정 "나중에 수동 트리거" | **이미 처리됨** — W6-05/06/07에서 실제로 수동 트리거해 완주(증거: `W6-06_retrain_evidence.md`). 당시 메모가 그대로 남아 있었을 뿐, 현재 기준으론 전부 완료 상태 |

### 조치

- 체크리스트 줄 133을 위 표의 ①②로 갱신 — "후속 단계"/"보류"라는 애매한 표현을
  "재업로드 안 함(확정)"/"+100건 착수 안 함(확정)"으로 명확히 닫는다.
- W8-07 향후 과제 표에 11번째 항목 추가: `rays`/`grid_delta` 트레이드오프 검증(여전히
  미확인, 트리거는 안 울렸지만 공식적으로 검증한 적은 없음).

## 3. 게이트 G8 판정: README·발표·태그·백업 영상·증거 파일이 모두 있다

| 기준 | 상태 |
|---|---|
| README | 있음 |
| 발표 | 있음(저장소 밖, PDF로 사용자 보관) |
| 증거 파일 | 있음(`reports/evidence/` 90개 이상) |
| **태그 v1.0** | **없음** — git 태그는 내가 실행할 수 없는 작업이라 아직 생성 안 됨 |
| **백업 영상** | **없음** — 위 §2와 동일, 사용자가 GPU 환경에서 추후 녹화 |

**판정: 조건부 충족(준비 완료, 실행 대기 2건)** — "모두 있다"를 문자 그대로 판정하면
아직 미충족이다. 다만 남은 2건(태그, 백업 영상)은 **내가 할 수 없는 사람의
행동**이고, 둘 다 구체적인 다음 단계(태그 명령 제공됨, 데모 대본·리허설 기록표
준비됨)가 이미 있어 "막혀 있는" 상태는 아니다. 사용자 확인 없이 "완전 충족"으로
적지 않는다[확인, CLAUDE.md 4·7항].
