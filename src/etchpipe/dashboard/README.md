# EtchGuard 대시보드

`static/index.html`을 Chrome에서 열면 Golden10 `r0007`의 2분·5분 단면을 비교할 수 있다. 합성 응답은 실선이고 ViennaPS 기준은 점선이다. 시간 선택, 두 시간 겹치기, 제출 레시피 확인, PNG 저장은 오프라인으로 실행한다.

이 작업은 W7-01의 레시피 입력·예측 화면과 `r0007` 비교 시연을 포함한다. 기준 파일의 레시피와 제출 조건이 일치할 때만 기준선을 표시한다.

## 서빙 연동

- `main`의 FastAPI는 `GET /health`, `GET /model`, `POST /predict`를 제공한다. `/model`과 `/predict`는 서버에 설정한 API 키로 인증한다.
- 화면의 API 호출 경로는 같은 출처의 `/api/predict`다. 연동 시 서버 측에서 FastAPI의 `/predict`로 전달하고 인증 헤더를 추가한다. 브라우저에 키를 넣을 필요는 없다.
- 팀 환경을 받으면 `/health`, 인증된 `/model`, 인증된 `/predict` 순으로 확인한다. `r0007`의 2분·5분 프로파일, 모델 버전, 입력 범위 경고, 실제 반환 시간을 화면에 대조한다.
- 여러 모델의 비교와 게이트 이력 조회에는 해당 결과의 조회 경로와 응답 형식이 필요하다.
